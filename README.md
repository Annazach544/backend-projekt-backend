# Bistro Anna - Backend

Detta projekt är backend-delen av Bistro Anna och består av en REST-baserad webbtjänst skapad med Node.js och Express.

Webbtjänsten hanterar restaurangens meny och använder JWT för skyddade resurser.

## Funktioner
- Hämta maträtter
- Skapa maträtter
- Uppdatera maträtter
- Radera maträtter
- JWT-baserad autentisering

## Teknologier
- Node.js
- Express
- MongoDB Atlas
- Mongoose
- JSON Web Token
